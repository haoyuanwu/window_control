# 窗口工具扩展需求

## 范围

提供稳定自由缩放、单边缩放、比例缩放、自由移动、窗口尺寸预设、居中、应用排除、20 步撤销、窗口几何记忆、托盘及可选登录启动。已移除的贴靠布局与分屏预览不恢复。

所有新能力需要单独验证；跨平台实现文件存在不能视为 macOS 已可用。

## 默认与持久化

| 字段 | 默认 | 行为 |
| --- | --- | --- |
| enabled | false | 运行期状态，不直接从磁盘恢复 |
| resizeKeys | ctrl + alt | 一组非空多选修饰键 |
| moveKeys | ctrl + shift | 与普通/比例缩放均不得冲突 |
| excludedApps | 空列表 | 原生应用身份匹配，排除项不参与本工具控制 |
| edgeResize | true | 靠近窗口边缘时支持单边缩放 |
| rememberWindows | false | 只学习本工具完成的操作 |
| launchAtLogin | false | 仅用户主动开关时写系统登录设置 |
| autoEnable | false | 用户显式开启后，下次启动有权限才启用 |
| closeToTray | true | 图标成功建立后关闭才隐藏 |

支持 ctrl / alt / shift / meta。按下鼠标时精确匹配组合。比例模式为 resizeKeys 额外 Shift，若已有 Shift 则额外 Alt；派生集合必须不同于普通缩放且不等于 moveKeys。若无法形成独立组合应阻止保存并说明原因。

除 enabled 外配置与尺寸预设由 Flutter 保存。错误、缺失或旧配置迁移应安全使用默认值；写入失败必须提示。autoEnable 与 launchAtLogin 独立，启动读取配置不得隐式写登录设置。Windows Run 与 macOS 13+ SMAppService 登录项的开启/关闭均须源自用户主动切换；开发验证不能修改真实登录设置。

## 缩放和移动

鼠标左键按下时锁定目标身份、起始几何、起始鼠标和移动/缩放主模式，后续跨中心、跨窗口、跨屏不重新命中。缩放中可按住或松开额外比例键切换比例约束，不能因此切换为移动动作。四象限缩放固定对角，单边模式固定对边；比例模式保持起始宽高比并尊重应用尺寸限制。边缘命中与比例模式的优先级应明确：比例模式使用角缩放，不能在单边操作中意外破坏比例。

以起始几何和当前位移计算，不累积当前几何误差；合并高频采样，不向慢窗口无界排队。尺寸钳制后按实际尺寸保持固定角/边。起始小窗口不因硬编码最低尺寸跳大。移动只改变位置，避免每帧重写尺寸。

释放鼠标提交最新位移，提前松开修饰键提交已完成结果，之后不再控制窗口。Esc 恢复手势前几何，不写撤销记录。停用、改配置、权限失效、退出须及时结束手势并释放输入状态。无变化点击不记历史。失败和超时应安全停止并反馈，不能反复还原导致跳动。

## 窗口操作与撤销

列表列出可控制窗口 id、title、app。选中后可应用自定义宽高并选择是否居中，也可单独居中。单独居中只调整位置，超屏大窗口尽量使标题栏可操作，不缩小原尺寸。预设只保存于 Flutter，调用原生前验证为 100..16384 范围内的整数。操作使用目标显示器工作区，处理 DPI、负坐标及应用最小尺寸；受约束结果不能谎报精确尺寸已应用。

每次完成的缩放、移动、尺寸预设、居中记录操作前几何，最多 20 步，移除最旧记录。restoreLast 撤销最近一个有效操作；窗口关闭、句柄复用或身份变化不能误控新窗口。失败应反馈，不能报告已恢复。undoCount 表示当前可用历史数量，撤销和无效记录处理后立即同步。

## 排除与记忆

应用排除依据稳定原生身份，不能单纯依赖标题。排除应用不参与手势、预设、居中和自动记忆恢复。

rememberWindows 只学习本工具完成的操作，不能持续监控用户或系统的普通窗口移动。Windows 以 exe + class、macOS 以 bundleID 识别。开启后仅对后来出现的新窗口恢复；不重新排列开启选项时已经存在的窗口，也不抢焦点。首版按应用类别共享最后一份几何：Windows 为同 exe+class，macOS 为同 bundleID；同类后来出现的多个窗口可能恢复到相同位置，不承诺每个窗口独立记忆。每个新窗口仅恢复一次，已有窗口不反复重排。记忆恢复至少使标题栏和可操作区域位于现有工作区，处理显示器断开及不同 DPI。关闭记忆后停止自动恢复。

## 托盘和登录启动

托盘菜单提供显示、启用/暂停、撤销和退出；菜单状态须与原生服务一致。closeToTray 真但图标创建失败时保持窗口可见，不能隐藏后无入口恢复。退出要结束监听与后台任务。

登录启动写入结果必须真实反馈；可执行路径正确引用，程序移动后失败可诊断。开关读回不能仅使用乐观 UI 状态。macOS 13+ SMAppService 登录项注册、注销与系统状态需本机验证；旧系统明确提示不支持。

## 平台边界

Windows 普通权限不承诺控制提升权限窗口。macOS 必须检查辅助功能和输入监控；独立分发且关闭 App Sandbox 已获授权，但 Apple SDK 编译、真机手势、登录项、签名、公证均尚待验证。不可缩放、最小化、系统全屏、桌面和特殊系统窗口不在默认支持范围；最大化窗口须单独验收。
