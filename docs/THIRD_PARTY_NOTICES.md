# 第三方组件

Window Control 使用 Flutter / Dart、Flutter Material Icons 及 cupertino_icons。Flutter 生成的第三方许可清单随应用发布于 data/flutter_assets/NOTICES.Z；各组件的许可仍归其权利人所有。

Windows 发行包附带从 Visual Studio 官方 Redist x64 目录取得的 Microsoft Visual C++ Runtime DLL，以应用本地方式加载，避免要求用户单独安装开发工具。Microsoft 组件受其原有许可条款约束，版权归 Microsoft Corporation 所有。本项目不对这些 DLL 主张权利。

安装程序使用 Inno Setup 生成；Inno Setup 的版权与许可参见 https://jrsoftware.org/ 。便携单 EXE 启动器使用 Windows .NET Framework。
