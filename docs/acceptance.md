## 配置和协议

- [ ] configure 全字段默认值符合需求，保存、迁移、损坏与写失败处理正确。
- [ ] resize/move 非空、合法、不同；派生比例组合不同于普通缩放且不与移动冲突。
- [ ] resize 同时含 Shift 和 Alt 导致无法派生时明确拒绝，不能误判模式。
- [ ] enabled=false 先停监听再校验；非法编辑不会留下旧钩子继续运行。
- [ ] autoEnable 默认 false；真时有权限才启动；launchAtLogin 不隐式决定服务是否启用。
- [ ] launchAtLogin 状态读回真实，普通 configure、初始化和测试不写真实登录设置。
- [ ] 尺寸预设 Flutter 持久化，非法/非有限/非正尺寸不能进入原生操作。

## 缩放、移动和输入

- [ ] 四象限固定对角；边缘单边固定对边；比例模式保持起始宽高比并优先使用角缩放。
- [ ] 移动只改位置，尺寸不变；手势锁定目标与模式，穿过中心/其他窗口/屏幕不切换。
- [ ] 高频采样合并，慢窗口无长期排队；停止鼠标后几何及时收敛。
- [ ] 最小尺寸、步进限制与起始小窗口无跳大、翻转和锚点漂移。
- [ ] 松开鼠标提交最新位移；释放修饰键、Esc、禁用、退出、权限失效后无输入残留。
- [ ] 普通点击、额外修饰键和未匹配组合完全透传。
- [ ] 负坐标、多屏与混合 DPI 下移动/缩放稳定。

## 窗口列表、预设、居中和撤销

- [ ] listWindows 的 id/title/app 正确，排除与不可控制窗口不出现在可用列表中。
- [ ] 窗口关闭后旧 id 安全失败，句柄复用不误控新进程。
- [ ] 预设宽高、可选居中与单独居中使用目标工作区并尊重实际尺寸约束。
- [ ] 缩放、移动、预设、居中均记操作前几何，最多 20 步；无变化/取消/失败不污染历史。
- [ ] 连续撤销及无效目标处理正确，undoCount 与托盘/界面同步。

## 排除和记忆

- [ ] excludedApps 使用稳定身份，手势、预设、居中、自动恢复均遵守排除。
- [ ] 记忆默认关闭，只学习本工具完成的操作，普通系统移动不学习。
- [ ] 开启记忆不改已有窗口；新窗口按 exe+class / bundleID 匹配，不抢焦点。
- [ ] 同应用类别新窗口共享最后几何的行为与说明一致，每个新窗口仅恢复一次；显示器断开及 DPI 变化后仍可见。
- [ ] 关闭记忆后停止恢复，文件损坏或写失败安全处理。

## 托盘、登录启动和权限
