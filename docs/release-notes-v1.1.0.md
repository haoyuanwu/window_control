# Window Control 1.1.0

首个 Windows x64 发布版，提供自定义快捷键配合鼠标的窗口操作。

## 功能

- 从任意位置缩放、移动窗口；移动时自动带到前景。
- 额外按键保持比例，窗口边缘单轴缩放。
- 自定义尺寸预设、窗口居中、最多20步撤销。
- 应用排除、同类新窗口的位置尺寸记忆。
- 系统托盘常驻，独立的登录启动与自动启用设置。

## 下载选择

- **Setup**：推荐，当前用户安装，无需管理员权限，有快捷方式与卸载入口。
- **Portable**：单 EXE，自动释放运行资源，适合免安装使用。
- **ZIP**：完整运行目录，解压后运行 window_control.exe。
- **SHA256SUMS.txt**：上述文件的 SHA256 校验值。

默认 Ctrl+Alt+左键缩放，Ctrl+Shift+左键移动，缩放时额外Shift保持比例。首次运行请开启服务；关闭设置默认隐藏到托盘，完全退出请使用托盘菜单。升级前先退出旧版本。

## 已知边界

仅发布 Windows x64。macOS 代码尚未编译/真机验证；本次不提供 Mac 安装包。管理员权限、系统保护、不可缩放、最大化等窗口不在普通窗口操作承诺范围。程序与安装包未代码签名。

验证记录：Flutter 静态检查通过，14项Flutter测试与76项受控原生检查通过；最终受控运行2项系统输入检查因桌面环境跳过。完整第三方应用、混合DPI、真实登录启动和完整托盘交互仍需实际体验。
